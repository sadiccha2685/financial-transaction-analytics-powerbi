# 🏦 FinSight: Financial Analysis & Transaction Insights Dashboard

## 📌 Project Overview
**FinSight** is an end-to-end interactive Power BI dashboard designed to monitor transaction flows, customer segments, fee dynamics, and geographical revenue distribution[cite: 4, 5]. It translates complex transaction records into real-time operational metrics to analyze financial risk, transaction status, and customer behavior[cite: 4, 5].

---

## 📊 Key KPIs & Metrics (Overview Analysis)
* **Total Volume & Amount:** Real-time tracking of overall transaction amount (₹135.62M) and volume (15.03K transactions)[cite: 4].
* **Financial Overhead:** Live tracking of Avg. Transaction Value (₹9.02K), Total Fees (₹217.30K), and Total Tax (₹39.14K) with year-over-year growth indicators[cite: 4].
* **Monthly Trends:** Line graph tracking transaction fluctuations across months[cite: 4].
* **Status Distribution:** Donut chart analyzing Success, Failed, and Pending transaction rates[cite: 4].
* **Geographic Insights:** State-wise breakdown showing top revenue regions (e.g., Maharashtra, Karnataka, Gujarat)[cite: 4].
* **Demographic & Segment Analysis:** Breakdown of transaction volumes across Customer Segments (Retail, Premium, SME, Corporate, Wealth), Gender, Occupation, and Category filters[cite: 4].

---

## 📋 Granular Transaction Analysis
* **Customer-Level Ledger:** Detailed transactional table tracking Transaction ID, Customer Name, Date, Type (Loan EMI, Transfer, Deposit, Card Payment), Status, and State[cite: 5].
* **Financial Breakdowns:** Granular auditing of Total Amount, Total Fees, and Total Tax per transaction record[cite: 5].

---

## 🛠️ Tools & Technologies
* **Power BI Desktop:** DAX measures, dynamic metric switching, and interactive dashboard layout[cite: 4, 5].
* **Power Query:** Data cleaning, transformations, and schema structure[cite: 4, 5].
* **Source Data:** Financial transaction dataset (`.pbix`)[cite: 5].
